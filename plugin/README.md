# Context Glance · 上下文仪表盘

**简体中文** | [English](README.en.md)

在 Antigravity App 的辅助面板查看宿主上下文压缩预算、剩余 Token、请求明细与最近实际请求使用的模型。支持六套配色与三档字号。

支持中英文界面：首次跟随浏览器语言，也可手动切换，并保存选择。

已在 Windows + Antigravity App 2.31.2 实机验证。需要宿主的 Sidecar WebUI、内置 Node 与 Sidecar SDK，无需 npm 依赖。其他版本或桌面平台未做完整验证。

从完整源码本地安装可在上级项目目录运行 `Install.ps1`；已安装 CLI 时，可使用 `agy plugin install ./plugin`，或在仓库公开后使用其 `tree/main/plugin` 链接。安装并启用后，从会话标题的 `+` / 扩展菜单打开「上下文仪表盘」。

## 数值含义

- 占比默认以宿主当前压缩预算为分母；256k 的宿主预算不等于模型标称总窗口。
- 手动基准只影响显示，不能扩大模型窗口或关闭压缩。
- 模型卡来自当前会话最近实际请求，切换模型并产生新请求后更新。
- 状态接口不可用时降级为本机日志；无参考基准显示 `--`，模型未知时不猜测。

## 只读与隐私

仅访问本机状态与当前会话日志，不发起模型推理，不向对话注入内容，不修改模型或宿主设置。无 Skills、Rules、MCP、Agents 和 Hooks。端口由宿主分配，仅绑定本机回环地址。

用量和模型读取依赖宿主内部协议，升级后可能不可用。元数据接口可能返回额外本机字段；插件只保留数值和模型身份，其余字段不保存或传给模型。面板隐藏后停止轮询，后端约 12 秒空闲后回收订阅。

宿主连续失联后，本插件会关闭自己的订阅和 HTTP 服务并退出，避免成为孤立进程。该机制不结束内置 Swarm 或其他插件；隐藏面板时宿主仍存活，进程继续由宿主管理。
